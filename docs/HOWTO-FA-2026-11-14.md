## ۲) کار روزمره (پنج دستور)

```bash
cd ~/gozar

gozar calibrate                 # ۱. سقف پینگ خط خودتان
gozar discover -n 20 -t "$T"     # ۲. کشف و تست روی هدف شما
gozar list                       # ۳. ببینید چه ماند
gozar connect                    # ۴. وصل شو (best)
gozar check                      # ۵. هر چند ساعت: بازآزمایی
```

| دستور | کار |
|---|---|
| `discover` | منابع را می‌خواند، نودها را با sing-box واقعاً تست می‌کند، `best/bak/gen` را می‌نویسد |
| `check` | همان نودهای ذخیره‌شده را دوباره تست می‌کند، مرده‌ها کنار می‌روند |
| `run` | `discover` + `connect` در یک قدم |
| `list` | جدول `best`/`bak`/`gen` را نشان می‌دهد (`--recheck` برای تست فوری) |
| `pick` | منوی تعاملی برای انتخاب نود و وصل شدن |
| `connect` | sing-box را روشن می‌کند (`--from gen` اگر هدف رد شده ولی نود زنده است) |
| `verify` | فقط «آیا این نودها واقعاً تونل می‌کنند؟» با اثبات IP خروجی |
| `sources` | **تازه:** رتبه‌بندی منابع نسبت به یک هدف |
| `config` | دیدن/عوض‌کردن تنظیمات (`--set KEY=VALUE`, `--get KEY`, `--doctor`) |

## ۳) برای هدف دلخواه `$T` چطور فراخوانی کنم

`$T` را هرجا می‌خواهید بگذارید؛ سه جا `-t` را قبول می‌کند:

```bash
T='https://www.google.com.hk/search?q=test&udm=50'

gozar discover -n 20 -t "$T"       # کشف/تست روی این هدف
gozar verify  -n 6  -t "$T"        # فقط اثبات نودهای موجود
gozar sources -t "$T" --per-source 16 --propose   # رتبه‌بندی منابع
```

قواعد:
- `-t` را می‌شود چند بار داد: `-t A -t B` یا `-t 'A,B,C'` — نود باید **همه** را پاس کند.
- `-t` را خالی بگذارید = حالت «فقط زنده بودن» (بدون هدف).
- `-t` را می‌شود در `config.json` دائمی کرد:
  `bot config --set 'targets=https://example.com/,https://www.google.com/'`
- `connect`/`pick`/`list` فلگ `-t` ندارند؛ هدفشان از config/آخرین اجرا می‌آید.

### خروجی واقعی روی دو هدف مختلف (همین حالا، ۶ نود استخر شما)

```
T = https://example.com/                     T = google.com.hk/search?...&udm=50
TUNNELED ✓ shadowsocks 173ms target=ok        TUNNELED ✓ shadowsocks 174ms target=http_429
TUNNELED ✓ wireguard   327ms target=ok        TUNNELED ✓ wireguard   120ms target=js_shell
TUNNELED ✓ wireguard   174ms target=ok        TUNNELED ✓ wireguard    97ms target=js_shell
summary: tunneled=4 leaked=0 unverified=0     summary: tunneled=4 leaked=0 unverified=0
```

هر دو ستون **درست** است، و همین نکتهٔ اصلی است:
- `target=ok` = صفحهٔ واقعی آمد.
- `target=js_shell` = ۹۳KB آمد ولی ۱۷ کلمه متن بود: **دیوار جاوااسکریپت گوگل**، نه نتیجه.
- `target=http_429` = گوگل گفت «ترافیک مشکوک»؛ تونل کار کرد، گوگل IP دیتاسنتر را throttle کرد.

پس برای **بررسی سلامت خط و نودها** از `example.com` (یا `generate_204`) استفاده کنید؛
گوگل را با `--strict-target` جدا بسنجید. عدد `target=ok` روی گوگل عملاً هیچ‌وقت سبز نمی‌شود.

## ۴) منابع ایرانی: جواب روشن

**منبع ایرانی که بشود مستقیم در کد گذاشت پیدا نشد.** دلیلش این است که کانفیگ در
ایتا/روبیکا **متن پست** است، نه لینک ساب پایدار؛ و هاست‌های داخلی که ساب می‌دهند
عمدتاً شخصی/موقت‌اند. طبق تصمیم شما **هیچ‌کدام به کد اضافه نشد**.

### سه راه اضافه‌کردن (بدون دست‌زدن من به کد)

```bash
# ۱) فایل: هر ردیف vless:// vmess:// trojan:// ss:// hysteria2:// را در یک فایل بریزید
gozar discover -i ~/iran-subs/mci.txt -t 'https://www.aparat.com/'

# ۲) لینک ساب داخلی، دائمی در config:
```

`http://eitaa.com/`, `https://www.aparat.com/`, `https://divar.ir/`, `https://www.digikala.com/`.

## ۵) تنظیمات مفیدی که با یک دستور عوض می‌شوند

```bash
bot config                                  # همه‌چیز را با منبعِ هر مقدار نشان می‌دهد
bot config --doctor                         # فقط ترکیب‌هایی که بی‌صدا نود می‌خورند
bot config --get best_n
bot config --set best_n=20
bot config --set 'targets=https://example.com/'
bot config --set protocol_list_note=...     # (نام کلید واقعی: protocols)
bot config --unset protocols                # قفل قدیمی protocols را بردار (doctor همین را می‌گوید)
bot config --set 'domestic_sources=https://a.ir/x.txt,https://b.ir/y.txt'
bot config --set list_mode=live             # لیست = همهٔ زنده‌ها، نه فقط target-OK
```

> روی این ماشین `bot config --doctor` می‌گوید `protocols` در `config.json` قفل شده و
> **wireguard ندارد** — یعنی ۶ نود wireguard شما در کشف‌های بعدی خوانده نمی‌شوند.
> اصلاح: `bot config --unset protocols`

## ۶) خطاهایی که دیگر نباید ببینید (و حالا معنی دارند)

| پیام | معنی |
|---|---|
| `target=js_shell` | ۲۰۰ آمد ولی صفحه نبود (دیوار JS). تونل سالم است |
| `target=http_429` | گوگل throttle کرد. نود سالم است |
| `target=blocked` (۴۰۳) | مقصد رد کرد. تونل سالم است |
| `0 of N alive nodes passed the targets … best/bak EMPTY by design` | هدف روی خط شما/از این IPها پاس نمی‌شود؛ استخر زنده در `gen.txt` است |
| `--per-source must be at least 1` | ورودی بی‌معنی را حالا رد می‌کند |
| `target must start with http:// or https://` | همان |
