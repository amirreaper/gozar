# ممیزی کامل در محیط تازه — v2.1.5

## چطور تست شد

محیطی **کاملاً تازه** ساختم، همان‌طور که روی لپ‌تاپ شما هست:

```bash
mkdir /tmp/final && cd /tmp/final
python3 -m venv v
HOME=/tmp/final/home ./v/bin/pip install "git+https://github.com/amirreaper/gozar.git"
```

`HOME` تازه، venv خالی، هیچ چیز از قبل، هیچ لانچر کهنه‌ای.

## دو باگ واقعی که پیدا شد

### ۱) `drop` حذف نمی‌کرد

```
$ gozar drop a8dc9680
[INFO] deleted: shadowsocks 66.163.117.245:443
$ gozar list | grep -c ★
9      ← نه ۸
```

`drop` فقط `state.json` را می‌نوشت. ولی `list` و `connect` از
`best.json`/`bak.json`/`gen.json` می‌خوانند. پس نودِ «حذف‌شده» هم در لیست بود و
هم می‌شد بهش وصل شد.

**رفع:** یک تابع مشترک — `core_output.refresh_pool()` — فایل‌های استخر را از
روی state بازنویسی می‌کند، و **هم `drop` و هم `pick`** از همان استفاده می‌کنند.
قبلاً `pick` نسخهٔ خودش را داشت و `drop` هیچ نسخه‌ای.

### ۲) `drop 0` می‌توانست چند نود را پاک کند

هر آرگومان اول به‌صورت **پیشوند id** تطبیق داده می‌شد. `drop 0` هر نودی که idش
با `0` شروع می‌شد را حذف می‌کرد.

| ورودی | رفتار جدید |
|---|---|
| `drop 3` | ایندکس لیست (اول) — دقیقاً یکی |
| `drop a8dc9680` | تطبیق دقیق، بعد پیشوند |
| `drop 4f` | چند تطبیق → خطا با فهرست idها، **بدون حذف** |

## دو کمبود که برطرف شد

**هر `-h` حالا مثال دارد** (۱۶ از ۱۶). از یک جدول واحد در `cli.py` تولید
می‌شود، پس با پارسر هم‌گام می‌ماند و یک قرارداد (گروه ۳۷) عقب‌افتادگی را قرمز
می‌کند:

```
$ gozar drop -h
Removes one node from the stored state. ...

examples:
  gozar drop 3                          # by list index (see `gozar list`)
  gozar drop a8dc9680                   # by short id
```

**متن‌ها دیگر «bot» نمی‌گویند** (`doctor -h`، راهنمای `--pin`).

## اگر روی لپ‌تاپ شما هنوز خطا می‌دهد

چون در محیط تازه و تمیز همه‌چیز پاس شد، خطای باقی‌مانده تقریباً قطعاً از **نصب
قبلی** می‌آید. این را اجرا کنید و خروجی‌اش را بفرستید:

```bash
# ۱) کدام gozar اجرا می‌شود و از کجا؟
command -v gozar
head -1 "$(command -v gozar)"

# ۲) آیا همان مفسر پکیج را می‌بیند؟
"$(head -1 "$(command -v gozar)" | sed 's|^#!||')" -m gozar --version

# ۳) تشخیص کامل
gozar selfcheck
```

و راهی که همهٔ حالت‌های کهنه را دور می‌زند:

```bash
python3 -m venv ~/.gozar
~/.gozar/bin/pip install "git+https://github.com/amirreaper/gozar.git"
~/.gozar/bin/gozar selfcheck
~/.gozar/bin/gozar engine install --yes
~/.gozar/bin/gozar discover -n 20 -t https://example.com/
~/.gozar/bin/gozar list
```

نکته: اگر `~/.local/bin/gozar` از نصب‌های قبلی مانده، آن را بردارید
(`rm ~/.local/bin/gozar`) تا `gozar` خالی همان venv را صدا بزند.
