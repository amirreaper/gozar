# ممیزی سورس‌ها — چه چیزی حذف شد، چه چیزی ماند، چه چیزی تازه اضافه شد

تاریخ: ۲۰۲۶-۱۱-۱۴ · ابزار: `python3 tools/source_audit.py --verify 12`
مقیاس: **۳۹ سورس → ۷۳٬۵۳۷ لینک منتشرشده → ۲۱٬۹۷۰ اتصال یکتا**

---

## سنجه‌ها (و چرا این‌ها)

| سنجه | معنی | چرا مهم است |
|---|---|---|
| `links` | تعداد لینک‌هایی که پارس می‌شوند | اندازه‌ی خام سورس |
| `uniq` | تعداد **امضای اتصال** یکتا («نوع+سرور+پورت+uuid+SNI+path») | یک نود با ۵ برچسب مختلف = ۱ نود |
| `ONLY` | چند نود را **هیچ سورس دیگری** ندارد | ارزش واقعی؛ حذف این سورس چه چیزی را از دست می‌دهد |
| `dup%` | درصد هم‌پوشانی | اگر ۱۰۰٪ باشد سورس فقط ترافیک و زمان تست است |
| `live` | نرخ زنده‌بودن نمونه (TCP/QUIC) | سورس «تأییدشده» ولی مرده به کار نمی‌آید |

نکته‌ی کلیدی: **`ONLY=0` به‌تنهایی حکم حذف نیست.** یک سورس می‌تواند ارزان‌ترین راه
پر کردن سریع یک tier باشد (cascade قبل از رفتن به tier بعدی، همان tier را تست می‌کند).
پس فقط سورس‌هایی حذف شدند که **هم** صفر یکتا داشتند **هم** کپی سالم‌تری از همان داده
در tier دیگری موجود بود.

